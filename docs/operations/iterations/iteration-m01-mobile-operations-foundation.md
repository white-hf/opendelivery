# M01 移动端运营基础框架

状态：`COMPLETED`（2026-07-27）

## 背景与目标

运营人员需要在手机浏览器快速查看今日营业流程和阻塞事项。当前页面以桌面双栏、侧边导航和宽表格为主，手机上存在横向溢出、操作入口不易发现和地图空间不足的问题。本迭代先建立移动端基础壳层，不改变后端 API 或业务状态机。

## 范围

- 识别 320/375/414/768px 响应式断点并消除主页面横向滚动。
- 小屏将侧边导航转换为可关闭抽屉，保留页面权限和站点切换。
- 首页在手机上优先展示营业日 SOP 和下一步行动。
- 运营页面使用单栏容器和统一移动端间距；桌面布局保持不变。
- 为后续地图、卡片列表和底部操作栏预留统一 CSS 类。

## 非目标

- 本迭代不重写地图业务、不改变 API 契约、不实现司机 App 移动端。

## 验收与验证

- 手机宽度 320px 至 768px 无横向滚动。
- 导航可打开、切换页面并关闭；当前页面和站点上下文不丢失。
- 首页能看到今日流程、关键指标和下一步行动。
- 桌面端现有页面和 Playwright 回归不受影响。
- `pnpm run typecheck`、`pnpm run build` 通过。
