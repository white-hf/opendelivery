# M02 移动端核心运营流程

状态：`COMPLETED`（2026-07-27）

## 目标

让运营人员在手机浏览器完成订单准备、到仓批次查看、派送计划确认和包裹详情查询，不依赖横向滚动或桌面专用双栏布局。

## 本次切片

- 订单准备在小屏采用单栏筛选与地图/列表顺序布局。
- 到仓清单将车次/笼板控制区和地图区纵向排列，保持选择状态和包裹分布。
- 派送计划保持 SOP 步骤语义，步骤条可横向查看，地图高度适配手机视口。
- 包裹、司机和到货明细继续使用现有 API、站点隔离和权限规则。

## 验收

- 320–768px 无页面级横向溢出；长表格仅在自身容器内滚动。
- 订单准备、到仓清单、派送计划在手机上可加载、筛选、选择和查看详情。
- 现有桌面布局、Google Maps 和 API 契约不变。
- `pnpm run typecheck`、`pnpm run build` 通过。
