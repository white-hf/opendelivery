# M03 移动端地图与异常操作

状态：`COMPLETED`（2026-07-27）

## 交付范围

- 在订单准备、到仓清单和派送计划页面增加固定底部高频操作栏，手机上可打开包裹工作列表/详情。
- 地图相关控制区在小屏使用纵向布局，避免固定侧栏挤压地图；列表仍通过抽屉或内部滚动查看。
- 底部操作栏仅在移动断点显示，桌面端保持原有浮动控件和布局。
- 保持现有地图点选、区域筛选、包裹选择、改派和异常处理 API 不变。

## 验收

- 手机端能从地图页面打开包裹列表或到仓明细，不需要精确点击小型浮动按钮。
- 底部操作栏不遮挡页面主要内容，内容底部预留安全间距。
- `pnpm run typecheck`、`pnpm run build` 通过。
