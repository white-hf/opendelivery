# M04：移动端派送地图优先布局

状态：COMPLETED

## 目标

让运营人员在手机上执行司机指派和包裹查看时，优先看到可操作地图，而不是被桌面端固定左栏挤压。

## 交付范围

- 派送计划步骤 3/4 在移动端隐藏固定司机控制栏，地图占满主要工作区。
- 地图顶部提供司机选择按钮，使用底部抽屉展示可用司机、容量和当前选择。
- 包裹明细继续使用地图内浮层，并适配窄屏宽度；底部操作条打开明细。
- 桌面端原有左右分栏、司机容量抽屉和包裹表格行为保持不变。

## 验收标准

- 375px 宽屏进入步骤 3 后地图可见高度不少于 520px。
- 司机选择、清除司机筛选、打开包裹清单均无需横向滚动。
- 选中司机或区域后，地图筛选结果与包裹清单保持一致。
- `pnpm run typecheck` 与 `pnpm run build` 通过。
