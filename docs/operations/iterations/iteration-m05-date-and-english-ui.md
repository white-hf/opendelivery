# M05：移动日期入口与英文界面清理

状态：COMPLETED

## 问题

移动端响应式规则隐藏了全局营业日选择器；英文 locale 下部分工作台仍直接渲染中文硬编码。

## 实现范围

- 在手机导航栏保留站点和营业日选择器，并压缩为适合窄屏的控件尺寸。
- 清理运营面板、订单准备、到仓、派送规划、运单详情及配置页的高频中文界面文案。
- 为导航抽屉和营业日控件补充英文、法文和中文标签。
- 不改变营业日查询参数、站点切换或接口协议。

## 验收标准

- 375px 宽度仍可直接选择营业日。
- 切换 `en-CA` 后本迭代覆盖的核心工作台标题、操作按钮、表格列和提示不再出现中文硬编码。
- `zh-CN`、`fr-CA` 原有导航翻译不受影响。
- `pnpm run typecheck` 与 `pnpm run build` 通过。
