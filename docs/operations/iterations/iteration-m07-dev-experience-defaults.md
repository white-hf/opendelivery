# M07：开发体验默认登录与业务日期

状态：COMPLETED

## 背景

当前系统处于本地开发体验阶段，运营人员每次进入都需要手动输入测试账号，并手动切换到有完整演示数据的 2026-07-13。该优化只服务开发环境，不应把测试凭据带入生产构建。

## 目标

- 开发模式登录页预填现有体验账号 `opsadmin / password123`，用户可直接点击登录。
- 开发模式在 URL 未携带合法 `date` 时，将营业日默认为 `2026-07-13`。
- URL 中明确指定的合法日期始终优先，生产构建继续使用当前日期且登录表单为空。

## 验收标准

1. `pnpm dev` 打开登录页后，用户名和密码字段均已有值，点击登录即可提交。
2. 登录后无日期参数时，请求和页面显示日期为 `2026-07-13`。
3. `#page=orders&date=2026-07-20` 等合法 URL 日期不被覆盖。
4. `pnpm run typecheck` 与 `pnpm run build` 通过。

## 实施结果

已完成开发模式登录预填和 2026-07-13 日期回退；生产构建不注入测试凭据。
