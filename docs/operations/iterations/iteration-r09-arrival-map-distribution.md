# R09 到仓地图聚合与笼板包裹分布修复

> 状态：`REVIEWED`（2026-07-27）；类型：运营 Web 缺陷修复；不改变司机 API、到仓状态机或数据库结构。

## 问题

订单准备页能够按配送区域显示地图聚合数量并点击展开；到仓清单虽然复用了 `PlanningMap`，但没有维护区域展开状态，笼板选择也不能驱动区域聚合/包裹点位联动，导致运营无法从笼板查看包裹地理分布。

## 目标与范围

- 到仓地图沿用订单准备页的区域多边形、聚合数量和点位样式。
- 选择某个笼板后，聚合数量只统计该笼板包裹；选择“全部车次包裹”统计整个到仓批次。
- 点击区域聚合数字或区域面后展开该区域的包裹点位；再次点击取消展开。
- 切换车次或笼板时清除失效的区域选择，地图适配当前数据范围。
- 包裹点位可点击并打开现有明细抽屉；不增加运营代司机扫描行为。

## DoD

- 单元测试覆盖笼板筛选、区域选择清理和可定位包裹映射。
- Web `typecheck`、Vitest、lint、build 通过。
- Playwright/浏览器验证：全车次聚合、单笼板聚合、点击聚合展开、点位明细和三语言渲染。
- 后端既有到仓 API 和数据库结构不变。
