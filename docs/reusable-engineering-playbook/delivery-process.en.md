# Agile Delivery Process

## Iteration loop

```text
Problem/goal → PRD → architecture/contract → iteration plan (REVIEWED)
            → vertical slice → validation evidence → summary → release/retrospective
```

- Commit only to verifiable vertical value slices.
- Deliver the minimum operable loop before automation, optimization, or benchmark features.
- Recheck dependencies, rollback, compatibility, and migrations for every change.
- Record unfinished work, baseline failures, and external blockers explicitly.
- Before handoff, verify that documentation, code, tests, migrations, and deployment configuration agree.
