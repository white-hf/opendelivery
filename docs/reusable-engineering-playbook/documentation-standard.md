# 文档规范

| 文档 | 目的 | 更新时机 |
|---|---|---|
| PRD | 用户、流程、范围、非目标、验收 | 产品行为变化前 |
| 系统设计 | 模块、依赖、接口、数据流、技术机制 | 架构变化前 |
| 数据模型/API 契约 | 表、字段、索引、请求响应、兼容性 | 数据或接口变化前 |
| 迭代计划 | 目标、任务、DoD、风险、依赖 | 开发前，标记 REVIEWED |
| 测试计划/证据 | 场景、数据、命令、结果、基线 | 开发中和验收时 |
| 执行总结 | 实际变更、证据、遗留问题、回滚 | 迭代结束 |
| ADR | 重要技术选择和取舍 | 决策形成时 |

文档要求：短句、明确责任、可执行命令、可验证指标；业务文档和技术文档分离；重要文档中英文同步；链接必须指向当前有效版本。
