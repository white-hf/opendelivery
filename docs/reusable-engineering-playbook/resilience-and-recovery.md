# 容错与可恢复设计

- 每个外部调用设置连接、读取和整体超时；超时是可观测的业务结果，不是无限等待。
- 只对明确可重试的错误重试，使用指数退避、随机抖动和最大次数；非幂等写入必须先有幂等键。
- 对上游重复推送、网络重放、消息重复消费实现幂等；以业务唯一键和状态条件保护数据库写入。
- 下游不可用时使用队列、Outbox 或人工可重放任务；不把失败吞掉而不留记录。
- 对部分成功的批处理提供逐项结果、补偿动作和重试入口。
- 关键迁移采用灰度、feature flag 或兼容读写；每个发布都有回滚条件和数据恢复方案。
- 记录 request id、业务 id、重试次数、耗时和最终结果；敏感数据脱敏。
