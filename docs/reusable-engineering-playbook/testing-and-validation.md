# 测试与验证

## 测试金字塔

1. 单元测试：状态机、策略、解析、校验和纯函数，快速覆盖边界条件。
2. Repository/集成测试：真实数据库或容器数据库验证事务、索引、约束和投影字段。
3. API 测试：认证、权限、错误码、幂等、分页和兼容响应。
4. E2E：从真实用户流程验证跨模块闭环；测试数据必须有命名空间、可重复、可清理。
5. 性能测试：以目标数据量验证慢查询、并发写、队列积压和 p95/p99 延迟。

## 验证规则

- 每个缺陷先添加能复现它的测试，再修复代码。
- 测试结果记录命令、环境、样本量、失败基线和剩余风险。
- 不把“编译通过”当作功能完成；至少需要行为证据或真实数据验证。
- 共享环境测试不得假定数据库为空，结束时清理自己创建的数据。
